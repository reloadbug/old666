# 老六清净 old666

> **老六最快** —— 一款无广告、纯绿色的 Windows 系统优化工具。
> 开机加速 · 运行加速 · 游戏加速。

不弹广告、不做全家桶、不偷跑后台。只解决用户真正在意的三件事：
**开机更快**、**久用不卡**、**一键净化不常用进程**。

---

## 核心特性

| 特性 | 说明 |
|---|---|
| 🚫 零广告 | 无推广位、无弹窗、无推送 |
| 🪶 极轻量 | 包体 ≤ 12 MB，常驻内存 ≤ 40 MB，冷启动 ≤ 1 s |
| 📦 绿色便携 | 解压即用，删除无残留，不写注册表 |
| 🔒 纯本地 | 默认不联网，不上传任何用户数据 |
| 🎯 一看就懂 | 一屏一焦点，主要优化收敛为一个按钮 |
| ↩️ 可回滚 | 每步操作留快照，一键恢复 |

---

## 功能模块

| 模块 | 能力 |
|---|---|
| **M1 开机加速** | 开机耗时时间线归因、启动项/服务/计划任务统一管理、风险分级、延迟启动 |
| **M2 进程净化** | 实时资源视图、不常用进程识别、智能分组、一键净化、白名单守护、一键回滚 |
| **M3 场景模式** | 日常 / 游戏 / 服务器三套规则方案，规则驱动、可解释、可自定义 |
| **M4 一键体检** | 30 秒扫描 → 健康评分 → 一键修复 → 前后对比 |
| **M5 内存与垃圾清理** | 工作集裁剪、临时文件/缓存/日志/回收站清理 |
| **M6 实时监控** | 桌面悬浮球，CPU / 内存 / 温度 / 网速，零打扰告警 |

---

## 技术栈

- **前端**：HTML / CSS / TypeScript（Tauri WebView2）
- **后端**：Rust
- **系统调用**：`windows-rs`（Win32 / PDH / 注册表 / SCM / 任务计划）
- **打包**：Tauri 2，产出绿色便携版

> 五层架构：UI 表现层 → 桥接层（Tauri IPC）→ 核心服务层（Rust 模块）→ 系统抽象层（windows-rs）→ 操作系统层

## 品牌标志

图形标源自商标原始 SVG（`assets/logo/source/reloadbug.svg`，925 KB / 1319 路径），
经路径抽稀、背景剔除与配色延展后产出产品用资源，**形状完全保留**。

| 文件 | 用途 | 体积 |
|---|---|---|
| `mark.svg` | 图形标 · 高保真（浅色背景） | 96 KB |
| `mark-dark.svg` | 图形标 · 深色背景版（灰阶反转） | 96 KB |
| `mark-flat.svg` | 图形标 · 扁平版（UI 内嵌 / 小尺寸） | 36 KB |
| `mark-mono-dark.svg` / `mark-mono-light.svg` | 单色版（印章 / 水印 / 深底） | 36 KB |
| `lockup-horizontal.svg` / `lockup-vertical.svg` | 组合标 | 36 KB |
| `app-icon.svg` / `app-icon-light.svg` | 应用图标（深色 / 浅色底） | 96 KB |

所有资源由 `tools/` 下的脚本自动生成，可随时重跑复现：

```bash
python tools/simplify-logo.py source/reloadbug.svg 0.6 1.2 mark.svg color
python tools/build-brand-assets.py      # 组合标 + 应用图标
python tools/build-brand-pages.py       # 品牌规范页
```
